# GigPilot 🎯

Paste any buyer message — get your battle plan: what they want, the deadline, the reference, your next step.

Live demo: https://gigpilot.odemakindeezekiel5.workers.dev

## Why
AI gig workers drown in buyer messages across email and marketplaces. Each one hides a trial task, a deadline, or a reference code in prose — and every missed deadline is money lost. GigPilot reads the message for you and turns it into a structured action card with a live countdown. Chaos in, battle plan out.

## Use it
Open `index.html` — no build step, no backend, no API key. Paste a message, hit Analyze, save the card to your action board. Data persists in `localStorage`.

- **Keyless AI extraction** via Pollinations (OpenAI-compatible) — nothing to sign up for.
- **Action board** sorted by urgency, then deadline. Overdue items glow red.
- **Tap any reference chip** to copy it.
- **"Try a sample"** loads a real buyer message so you see it work instantly.
